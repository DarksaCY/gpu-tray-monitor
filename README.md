# GPU Tray Monitor

Монитор двух видеокарт в системном трее Windows 11. Данные берутся из `nvidia-smi`, обновление раз в секунду.

## Значки в трее

По 5 значков на каждую видеокарту. Фон значка показывает карту, цветная полоска внизу — метрику:

| Полоска | Метрика | Значение на значке |
|---|---|---|
| 🔴 красная | Температура | `36°` (оранжевый ≥75°, красный ≥85°) |
| 🟢 зелёная | Загрузка GPU | `17%` |
| 🟣 фиолетовая | Загрузка VRAM | `97%` (в подсказке — ГБ) |
| 🟡 жёлтая | Потребление | `13` (ватты) |
| 🔵 голубая | Вентиляторы | `0` (реальные обороты, RPM) |

- **Тёмно-синий фон** — GPU 0 (RTX 3060)
- **Тёмно-зелёный фон** — GPU 1 (RTX 2070 SUPER)

Наведение на значок показывает подсказку с названием карты и точным значением.

Обороты вентиляторов читаются напрямую с тахометров через NvAPI (`ClientFanCoolersGetStatus`) — это фактические RPM каждого вентилятора, а не целевой процент. `0` означает, что вентиляторы физически остановлены (режим zero-RPM в простое — норма для RTX 3060 и 2070 SUPER: они запускают вентиляторы примерно с 55–60 °C). В подсказке видны обороты каждого вентилятора отдельно и процент duty cycle из nvidia-smi.

## Управление

- **Двойной клик** по любому значку — панель со всеми показателями в одном окне (поверх остальных окон).
- **Правый клик** — меню: показать панель, автозагрузка при входе в Windows, выход.

## Важно: как сделать значки видимыми

Windows 11 по умолчанию прячет новые значки в скрытую область (стрелка `^` возле часов). Чтобы видеть их постоянно:

1. Откройте стрелку `^` возле часов и **перетащите значки мышью на панель задач**, или
2. **Параметры → Персонализация → Панель задач → Другие значки на панели задач** — включите все значки GpuTrayMonitor.

## Сборка из исходника

```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /codepage:65001 `
  /out:GpuTrayMonitor.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll GpuTrayMonitor.cs
```

Зависимостей нет — используется только .NET Framework, встроенный в Windows.
