# GPU Tray Monitor

Монитор видеокарт NVIDIA в системном трее Windows 10/11. Показывает температуру, загрузку GPU, VRAM, потребление и обороты вентиляторов **прямо на значках** — без наведения мыши. Количество карт определяется автоматически, обновление дважды в секунду. По двойному клику открывается панель с графиками всех метрик в реальном времени.

## Скачать

Готовый `GpuTrayMonitor.exe` — на [странице релизов](https://github.com/DarksaCY/gpu-tray-monitor/releases/latest). Установка не требуется: скачайте и запустите. Файл не подписан сертификатом, поэтому Windows SmartScreen может предупредить о неизвестном издателе — нажмите «Подробнее» → «Выполнить в любом случае» (или соберите exe из исходника сами, см. ниже).

## Требования

- Видеокарта(ы) **NVIDIA** с установленным драйвером — данные берутся из `nvidia-smi` и NvAPI, которые входят в состав драйвера. Ничего дополнительно ставить не нужно.
- AMD и Intel не поддерживаются (у них нет nvidia-smi; поддержку можно добавить через собственные API вендоров).
- .NET Framework 4.x — уже встроен в Windows.

## Значки в трее

По 5 значков на каждую видеокарту. Фон значка показывает, к какой карте относится значок, цветная полоска внизу — метрику:

| Полоска | Метрика | Значение на значке |
|---|---|---|
| 🔴 красная | Температура | `36°` (оранжевый ≥75°, красный ≥85°) |
| 🟢 зелёная | Загрузка GPU | `17%` |
| 🟣 фиолетовая | Загрузка VRAM | `97%` (в подсказке — ГБ) |
| 🟡 жёлтая | Потребление | `13` (ватты) |
| 🔵 голубая | Вентиляторы | `0` (реальные обороты, RPM) |

Цвета фона по порядку карт: тёмно-синий (GPU 0), тёмно-зелёный (GPU 1), тёмно-фиолетовый (GPU 2), тёмно-коричневый (GPU 3); дальше палитра повторяется. Наведение на значок показывает подсказку с названием карты и точным значением.

Обороты вентиляторов читаются напрямую с тахометров через NvAPI (`ClientFanCoolersGetStatus`) — это фактические RPM каждого вентилятора, а не целевой процент. `0` означает, что вентиляторы физически остановлены: у большинства современных карт в простое работает режим zero-RPM, вентиляторы стартуют примерно с 55–60 °C. В подсказке видны обороты каждого вентилятора отдельно и процент duty cycle из nvidia-smi. Если на вашей карте NvAPI не отдаёт обороты (это зависит от поколения и вендора), значок автоматически показывает процент из nvidia-smi, а если и его нет — прочерк.

## Управление

- **Двойной клик** по любому значку — панель мониторинга (поверх остальных окон).
- **Правый клик** — меню: показать панель, цвет акцента, автозагрузка при входе в Windows, выход.

## Панель с графиками

Тёмная панель в «геймерском» стиле: на каждую видеокарту — карточка с пятью плитками (температура, загрузка GPU, VRAM, мощность, вентиляторы). На плитке — текущее значение, пик за окно и живой график за последние 60 секунд, который обновляется дважды в секунду. История копится и при закрытой панели, так что графики заполнены сразу при открытии.

- Шкала температуры, загрузки и VRAM — 0–100; у мощности и оборотов шкала подстраивается под пик автоматически.
- Панель перетаскивается за заголовок, закрывается крестиком или клавишей `Esc` (приложение при этом остаётся в трее).
- Цвет акцента (зелёный, красный, голубой) выбирается в меню по правому клику и запоминается между запусками.

## Важно: как сделать значки видимыми

Windows 11 по умолчанию прячет новые значки в скрытую область (стрелка `^` возле часов). Чтобы видеть их постоянно:

1. Откройте стрелку `^` возле часов и **перетащите значки мышью на панель задач**, или
2. **Параметры → Персонализация → Панель задач → Другие значки на панели задач** — включите все значки GpuTrayMonitor.

## Сборка из исходника

Компилятор входит в состав Windows — достаточно одной команды в PowerShell из папки проекта:

```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /codepage:65001 `
  /out:GpuTrayMonitor.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll GpuTrayMonitor.cs
```

Внешних зависимостей нет: один исходный файл, только .NET Framework и API драйвера NVIDIA.
